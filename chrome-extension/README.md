# 闲鱼Cookie获取Chrome扩展

## 功能简介
这是一个Chrome浏览器扩展，可以一键获取闲鱼网站的Cookie信息，方便配置闲鱼自动回复助手。

## 安装步骤

### 1. 打开Chrome扩展管理页面
在Chrome浏览器地址栏输入：`chrome://extensions/`

### 2. 开启开发者模式
在页面右上角找到"开发者模式"开关，打开它。

### 3. 加载扩展
1. 点击左上角的"加载已解压的扩展程序"按钮
2. 选择项目中的 `chrome-extension` 文件夹
3. 扩展图标会出现在Chrome工具栏中

## 使用方法

### 1. 打开闲鱼网站
在Chrome中访问 `https://www.goofish.com/`

### 2. 登录账号
使用您的闲鱼账号登录

### 3. 点击扩展图标
点击Chrome工具栏中的扩展图标

### 4. 获取Cookie
点击"获取Cookie"按钮，扩展会自动：
- 检测当前页面是否为闲鱼
- 获取所有相关Cookie
- 自动复制到剪贴板

### 5. 配置自动回复助手
将复制的Cookie粘贴到Web界面的配置页面即可。

## 功能特点
- ✅ 一键获取Cookie
- ✅ 自动复制到剪贴板
- ✅ 支持刷新Cookie
- ✅ 友好的用户界面
- ✅ 详细的操作提示

## 注意事项
1. 请确保在获取Cookie前已登录闲鱼账号
2. Cookie有效期有限，如果失效需要重新获取
3. 请妥善保管Cookie，不要泄露给他人
4. 仅限用于配置自动回复助手使用

## 故障排除

### 无法获取Cookie
- 确认已在闲鱼网站登录
- 确认当前标签页打开了闲鱼网站
- 刷新页面后重试

### 扩展不工作
- 检查是否正确加载了扩展
- 尝试重新加载扩展
- 检查Chrome扩展权限设置
